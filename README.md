# Financial Performance Business Intelligence Dashboard

## Project Status
Work in Progress

## Overview
This project is focused on developing a Power BI business intelligence dashboard using data from a previous financial statement analysis project completed in Microsoft Excel.

The dashboard will build upon the original analysis by transforming financial data into interactive visualizations that make it easier to examine company performance, identify trends, and communicate key business insights.

## Background
The original financial statement analysis examined Boston Beer Company's financial performance from 2021–2023 using Microsoft Excel. The analysis included financial statements, operating, investing, and financing activities, financial ratios, working capital, EBITDA, free cash flow, and other financial calculations.

## Current Work
The project is currently in development. Initial work includes organizing and preparing the existing financial data for use in Power BI.

## Planned Development
As the project progresses, the dashboard will be developed to support interactive financial analysis and visualization. This README will be updated to document the tools, methods, dashboard features, and insights as they are completed.
